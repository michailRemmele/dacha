---
title: "The editor's role"
description: "What the editor is, and what it is not."
---

The editor is a client of the same configuration the engine consumes. It is not a separate
runtime and it does not own a private format. Understanding this makes the rest of the
workflow, including script generation, straightforward.

## What this page will cover

- The editor as a reader and writer of the configuration
- Running the real engine inside the editing surface
- How the editor learns about your components and systems
- The extension bundle and the decorators
- What the editor deliberately does not do
