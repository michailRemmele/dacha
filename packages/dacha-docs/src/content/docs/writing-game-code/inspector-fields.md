---
title: "Inspector fields"
description: "Control how a component's fields appear in the editor."
---

The field decorator does more than mark a property as editable. It selects the widget the
inspector renders, seeds an initial value, and can group and label fields so a complex
component stays readable.

## What this page will cover

- Marking a field as editable
- Initial values and what they mean for the saved configuration
- The built-in widget types
- Labelling and grouping fields
- Writing a custom widget
- The widget schema and where it is registered
