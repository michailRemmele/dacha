The camera system decides which camera is current and keeps its projection in step with
the window. A camera is an ordinary actor carrying a camera component, so it can be moved
and parented like anything else.

## What this page will cover

- Registering the camera system
- The camera component
- Choosing the current camera
- Zoom and window size
- Following an actor
- Screen and world coordinates
