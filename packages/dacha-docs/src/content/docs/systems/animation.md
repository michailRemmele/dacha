---
title: "Animation"
description: "Drive component values over time with animation timelines."
---

The animator advances timelines attached to actors, changing component values frame by
frame. Timelines can flip through sprite frames or tween arbitrary numeric properties.

## What this page will cover

- Registering the animator
- The animatable component
- Frame timelines
- Tween timelines
- Grouping and switching between animations
- Editing animations in the editor
