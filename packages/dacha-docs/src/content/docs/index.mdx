<CardGrid stagger>
  <Card title="Describe the game as data" icon="document">

    bootstraps into a running world. [How it works](/introduction/how-it-works/)
  </Card>
  <Card title="Build it in the editor" icon="laptop">
    A desktop editor reads and writes that configuration, so scenes are assembled
    visually rather than by hand. [The editor's role](/concepts/editor-role/)
  </Card>
  <Card title="Extend it from the editor" icon="add-document">
    Generate a component, system or behavior from the interface. It is picked up by the
    game and registered in the editor automatically.
    [Scripts and auto-registration](/writing-game-code/auto-registration/)
  </Card>
  <Card title="Batteries included" icon="setting">
    Rendering on pixi.js, physics, animation, audio, input and interpolation ship with
    the engine. [Built-in systems](/systems/rendering/)
  </Card>
