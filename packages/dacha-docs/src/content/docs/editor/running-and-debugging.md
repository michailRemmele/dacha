The editor runs the real engine, so playing a scene inside it exercises the same code the
shipped game will. This page covers the playback controls and the tools for inspecting a
running game.

## What this page will cover

- Playing and pausing a scene
- What resets between runs and what does not
- Inspecting actors while the game runs
- The performance meter
- Reading engine errors
- Reloading the editor after changing project code
