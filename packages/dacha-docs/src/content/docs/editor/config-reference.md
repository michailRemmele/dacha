The editor reads a single configuration file from your project root. It tells the editor
where the game configuration lives, where assets are, which project events exist, and how
autosave should behave.

## What this page will cover

- Where the file lives and how it is located
- The path keys and what they point at
- Declaring project events
- The libraries key
- Autosave settings
- Overriding the file path from the command line
