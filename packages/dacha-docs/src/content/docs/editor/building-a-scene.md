Scene building is the editor's main job. This page covers adding and arranging actors,
working with the hierarchy, and the tools that make placement precise.

## What this page will cover

- Creating and switching scenes
- Adding actors, empty or from a template
- Arranging the hierarchy
- Selection, including multiple selection
- Moving, rotating and scaling
- Grid snapping and precise positioning
- Copy, cut, paste and the operation history
